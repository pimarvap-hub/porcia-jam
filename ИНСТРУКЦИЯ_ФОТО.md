### 3️⃣ Как добавить новые фото в галерею

**Шаг 1:** Скопируйте нужные фото в `app/public/img/`

**Шаг 2:** Переименуйте их понятно:
```
honey-1.jpg
honey-2.jpg
jam-production.jpg
jar-gift.jpg
restaurant-usage.jpg
etc.
```

**Шаг 3:** Отредактируйте файл `src/sections/Gallery.tsx` и добавьте в массив `galleryItems`:

```tsx
const galleryItems: GalleryItem[] = [
  // Honey & Jam Sticks
  { id: '1', img: '/img/honey-drip.jpg', alt: 'Стик натурального мёда', category: 'honey', title: 'Мёд в стиках' },
  // ... остальные
  
  // 🆕 ДОБАВЬТЕ НОВЫЕ:
  { id: '12', img: '/img/honey-1.jpg', alt: 'Ёмкость мёда', category: 'honey', title: 'Мёд в банке' },
  { id: '13', img: '/img/jam-production.jpg', alt: 'Процесс варки варенья', category: 'process', title: 'Производство' },
  { id: '14', img: '/img/jar-gift.jpg', alt: 'Подарочная упаковка', category: 'packaging', title: 'Подарок' },
]
```

**Шаг 4:** Сохраните и сайт обновится автоматически!

---

### 4️⃣ Категории фото

При добавлении выбирайте категорию:

| Категория | Когда использовать |
|-----------|-------------------|
| `honey` | Мёд, соевый соус в стиках |
| `jam` | Варенье (малина, клубника, смородина) |
| `packaging` | Упаковка, коробки, дизайн |
| `process` | Производство, применение в ресторане |

---

### 5️⃣ Оптимизация изображений

💡 **Совет:** Для быстрой загрузки сайта:
- Используйте **JPEG** для фотографий
- Используйте **WebP** для современных браузеров (они на 30% меньше)
- Размер: 800×600 пикселей или больше (сайт масштабирует сам)
- Сжимайте через [TinyPNG](https://tinypng.com/) или ImageOptim

### 7️⃣ Где брать фото для сайта?

**Используйте ВАШ товар!**
- 📷 Снимите красивые фото стиков на кофе
- 🎬 Снимите видео-гайф как открывается стик
- 🏪 Фото товара в магазине/ресторане
- 👥 Фото сотрудников, процесса производства
- 🎁 Фото подарочных наборов

**Инструмент для фото:**
- Даже iPhone/телефон даст хорошие снимки при хорошем свете
- Приложение Snapseed (Google) для редактирования
- Или Lightroom, Photoshop для профессионального вида
